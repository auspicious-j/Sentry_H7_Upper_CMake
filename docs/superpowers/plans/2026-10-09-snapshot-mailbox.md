# 异步输入快照与有效期实施计划

日期：2026-10-09。生命周期通知板块用户已确认 Keil 编译，已推送 GitHub 72db965。

**目标：** 固定容量最新值邮箱把外部发布与节点消费隔离；保留原始采样时间和发布序号，重复读取不能刷新数据年龄。
**边界：** 不修改旧 FrameSignal/Ports 保持语义、不改旧业务或 CubeMX；本板块实现 STM32 同步后端，不实现 ROS/模型库及事件队列。

## 步骤

- [x] 保存修改前基线；增加 ISnapshotLock 及 RAII guard，所有共享读写使用同一个同步对象。
- [x] 增加 TimedSnapshot<T>、SnapshotStatus/Freshness 和 LatestSnapshotMailbox<T>。固定存储，只接受可平凡拷贝数据，数据值 T 限制 128 bytes，元数据占用另计；禁止动态分配和外露共享引用。
- [x] publish(value,sampled_at_us) 在短锁内更新值、原始采样时间、序号及present。copyTo(destination) 一次读出完整副本，消费者在锁外使用。clear 使present=false但保留序号，不把0序号作为空判断。
- [x] 有效期检查使用同一个单调时钟域的now_us与sampled_at_us；timestamp=0合法；未来时间返回ClockMismatch而不是无符号下溢；age<=max_age_us为Fresh，超过为Stale，重复读取不改变样本字段。
- [x] STM32后端保存PRIMASK/关可屏蔽中断/内存屏障/恢复原PRIMASK；只用于单核普通任务及可屏蔽ISR，不能保护DMA、NMI、HardFault或另一核。
- [x] 新增纯框架示例根节点，内含低频发布与每帧读取两节点。每10帧发布，TTL=5000us；Debug可暂停发布；节点通过固定输入接口读取，并输出当前采样序号、年龄、状态与计数。
- [x] 样例时间由IClock提供，reader在取得快照后读取now，避免拿帧起点判断中途到达的数据。未来异步平台调用者自己保证时钟线程安全与域一致。
- [x] 接入g_robot_debug.snapshot和Keil演示cpp条目；新增函数/变量写短中文注释。
- [x] 静态检查、独立只读审查、更新文档后交给用户Keil编译。无编译、主机测试或仿真；用户确认后再提交推送。

## 观测预期

默认在原17节点9边上新增3节点1边，共20节点10条声明边，两计划均保留本链路。
帧号可被10整除时才发布，首次发布在第10帧；read_count每帧递增。暂停publish_enabled后序号不变、age_us继续增加且超过TTL后status=Stale；重新启用在下一个满足发布周期的帧发布。
首次发布之前状态为Empty，不把初始零值视作有效样本。当前演示没有独立超时计数；默认10ms发布间隔大于5ms有效期，持续发布也会经历Fresh/Stale。
此演示为同任务低频生产/高频消费，不代表已做多任务并发压力测试；跨线程同步仅由可替换锁后端承担。
